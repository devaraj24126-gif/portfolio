# ⚡ Getting Started

Clone the repository

```bash
git clone https://github.com/devaraj24126-gif/portfolio.git
```

Move into the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Production build

```bash
npm run build
```
